## 🚀 About the App

Ahmad Intelligence is a personal AI assistant designed to answer questions without requiring an internet connection for everyday conversations.

Unlike a typical website, the goal is to make it a standalone Windows desktop application that can be launched from its own app icon.

### ✨ Planned Features

- 🧠 **Offline AI:** Ask questions using a locally running AI model.
- 💬 **Chat Interface:** Interact with AI through a modern conversation interface.
- 💾 **Saved Conversations:** Keep chat history even after closing and reopening the app.
- 🖥️ **Windows Desktop App:** A dedicated application with its own name and icon.
- 🎨 **Modern UI:** A clean, attractive, and user-friendly design.
- 🔒 **Local Data Storage:** Store conversations on my own computer.

*These are planned features and will be implemented as development progresses.*

## 🛠️ Planned Technologies

- **Python** — application logic
- **PySide6** — desktop user interface
- **Ollama** — local AI model runtime
- **SQLite** — conversation storage
- **PyInstaller** — packaging the application for Windows
- **Git & GitHub** — version control and project management
- **ChatGPT** — AI-assisted development and problem-solving
